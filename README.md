# Savera Godhan Agri Farm (Savera Farms)

An e-commerce and subscription web platform for 100% pure A2 Vedic Gir cow milk, traditional Bilona ghee, fresh dairy products, cold-pressed oils, and farm-fresh essentials.

## Features

- **Storefront & Catalog**: Explore A2 Milk, A2 Bilona Ghee, fresh paneer, curd, and wood-pressed oils.
- **Flexible Subscriptions**: Daily, alternate day, or custom schedules with doorstep morning delivery.
- **Cart & Seamless Checkout**: Multiple payment options (UPI, Netbanking, COD) and address management.
- **Admin Operations Suite**: Complete order fulfillment, inventory tracking, raw materials, supplier management, route delivery dispatch, and reporting.
- **Responsive & Modern UI**: Built with Next.js App Router, Tailwind CSS, Lucide icons, and Framer Motion.

## Tech Stack

- **Framework**: Next.js 13 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: Framer Motion

## Local Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment

Deployable seamlessly on Cloudflare Pages and modern web platforms.
